# Control Integral Calego

Aplicación web de control operativo de CALEGO.

Producción: https://control-integral-calego.vercel.app

Backend centralizado en Supabase (Auth, PostgreSQL, RLS, Storage y Edge Functions) y hosting en Vercel.

Este repositorio contiene la V6 de producción. Nunca debe almacenarse una clave `service_role` de Supabase en el frontend o en el repositorio.
